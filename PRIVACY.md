# Privacy

The application does not upload data, collect telemetry or provide a remote-control listener. It reads display geometry and writes its settings, mission statistics and diagnostic files locally. Optional companion signalling uses local Windows named events. These local runtime files are excluded from this repository.

A public hosting provider still processes registration details and connection information under its own policy. Publishing source code cannot guarantee anonymity or prevent messages to the public project account. Do not put personal information, credentials or private diagnostics in public issues, commits or uploads.
